# split-tunnel-apps

Автоматически обновляемые списки Android-приложений для раздельного туннелирования.

- `public/direct_apps.txt` — приложения, которые должны идти напрямую.
- `public/proxy_apps.txt` — приложения, которые должны идти через VPN.

Парсеры ищут в отзывах только упоминания `VPN`, `ВПН` и `КВН`. Из отзыва извлекается предложение с таким упоминанием; если оно слишком длинное или без нормальной пунктуации, используется окно до 10 слов слева и справа. Полные отзывы и промежуточные результаты в репозитории не сохраняются.

Найденные контексты группируются по Android package ID и одним запросом на приложение отправляются в DeepSeek, который возвращает только `DIRECT` или `PROXY`.

Для GitHub Actions требуется Repository Secret `DEEPSEEK_API_KEY`. Модель можно переопределить Repository Variable `DEEPSEEK_MODEL`; по умолчанию используется `deepseek-chat`.
