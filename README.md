# split-tunnel-apps

Автоматически обновляемые списки Android-приложений для раздельного туннелирования.

Проект определяет не просто наличие упоминания VPN, а направление маршрутизации приложения:

- `PROXY` — приложение без VPN не работает, ограничено или VPN помогает получить доступ.
- `DIRECT` — приложение конфликтует с VPN, требует его отключить или обнаруживает активный VPN.

Для обычной конфигурации рекомендуется **DIRECT по умолчанию** и отправка через VPN только приложений из `proxy_apps.txt`.

## Результат

Основной список для обычного пользователя:

```text
public/proxy_apps.txt
```

```text
https://raw.githubusercontent.com/zuboleo/split-tunnel-apps/main/public/proxy_apps.txt
```

Обратный список для схемы «всё через VPN, кроме исключений»:

```text
public/direct_apps.txt
```

```text
https://raw.githubusercontent.com/zuboleo/split-tunnel-apps/main/public/direct_apps.txt
```

`public/app_ids.txt` сохранён для обратной совместимости и содержит тот же список, что `direct_apps.txt`.

Формат файлов — одна строка, Android package ID разделены запятыми.

## Как определяется маршрут

Раз в сутки проект собирает публичные публикации и отзывы из магазинов приложений. Текст анализируется одним общим ядром для всех источников.

Ядро ищет упоминания `VPN`, `ВПН` и `КВН`, рассматривает локальную фразу вокруг них и различает противоположные конструкции, например:

```text
не работает без VPN   -> PROXY
не работает с VPN     -> DIRECT
требует отключить VPN -> DIRECT
VPN помогает войти    -> PROXY
```

Для русского текста используются токенизация и нормальные формы слов, поэтому формы вроде `работает`, `работало`, `работали`, `запускается`, `запускалось` не требуют отдельного правила для каждого окончания.

Одного явного свидетельства может быть достаточно. Несколько более слабых свидетельств объединяются, а противоречащие друг другу сигналы оставляют приложение кандидатом до появления более уверенных данных.

## Данные

- `data/apps.json` — приложения, итоговый маршрут и уверенность.
- `data/evidence.json` — найденные свидетельства и их классификация.
- `data/seed.json` — исходный проверенный DIRECT-набор.
- `data/allowlist.txt` — принудительное включение в DIRECT.
- `data/proxy_allowlist.txt` — принудительное включение в PROXY для проверенных исключений из автоматической классификации.
- `data/denylist.txt` — исключение приложения из результатов.
- `public/status.json` — состояние последнего обновления.

## Источники

Используются публичные публикации и страницы/отзывы приложений. Предусмотрены адаптеры для Google Play, RuStore, Huawei AppGallery и Samsung Galaxy Store.

## Обновление

Списки пересобираются автоматически один раз в сутки через GitHub Actions.
