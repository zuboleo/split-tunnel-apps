# split-tunnel-apps

Автоматически обновляемые списки Android-приложений для раздельного туннелирования.

- `public/direct_apps.txt` — приложения, для которых есть явное свидетельство конфликта с включенным VPN.
- `public/proxy_apps.txt` — приложения, для которых есть явное свидетельство необходимости VPN для доступа или нормальной работы.

Парсеры ищут в отзывах только упоминания `VPN`, `ВПН` и `КВН`. Из отзыва извлекается только предложение с таким упоминанием; если оно слишком длинное или без нормальной пунктуации, используется окно до 10 слов слева и справа. Полные отзывы и промежуточные результаты в репозитории не сохраняются.

Предложения не считаются отдельными доказательствами. Фрагменты из одного пользовательского отзыва и ответ разработчика к нему остаются одним `report`; DeepSeek видит, какие сведения пришли из разных независимых отзывов и из какого магазина. Это позволяет отличать повторяющуюся проблему приложения от единичного сетевого сбоя или шаблонного совета поддержки.

На одно приложение отправляется один компактный запрос в DeepSeek. Внутренний ответ модели может быть `DIRECT`, `PROXY` или `SKIP`. Одиночные общие фразы вроде «с VPN не работает» или «без VPN не работает» без явной причинной связки считаются недостаточными. `SKIP` используется для простых упоминаний VPN, неоднозначных/противоречивых фраз и недостаточных свидетельств и нигде не публикуется.

Каждый запуск строит итоговые DIRECT/PROXY списки заново. Предыдущие публичные списки используются только как список package ID, которые нужно повторно проверить; старые классификации автоматически не переносятся. При ошибке классификации публикация прерывается целиком, чтобы не сохранить частичный результат.

Для GitHub Actions требуется Repository Secret `DEEPSEEK_API_KEY`. Модель можно переопределить Repository Variable `DEEPSEEK_MODEL`; по умолчанию используется `deepseek-chat`.
