# split-tunnel-apps

Автоматически обновляемый список Android-приложений, которые при активном VPN могут показывать предупреждение, требовать отключить VPN или ограничивать доступ к части функций.

Репозиторий предназначен для **раздельного туннелирования**: найденные Android package ID можно использовать как список приложений, которые следует направлять напрямую, в обход VPN.

## Что делает проект

Раз в сутки проект:

1. Ищет новые публичные упоминания приложений, конфликтующих с VPN.
2. Анализирует найденные страницы, публикации и отзывы.
3. Определяет, о каком Android-приложении идет речь.
4. Получает его `package ID` из доступных источников и магазинов приложений.
5. Сохраняет подтверждения и исключает дубликаты.
6. Пересобирает актуальный список package ID.

В список не должны попадать все российские приложения подряд. Цель — хранить только приложения, для которых найдено свидетельство проблемы при активном VPN.

## Результат

Основной файл:

```text
public/app_ids.txt
```

Формат — одна строка, package ID разделены запятыми:

```text
com.example.one,com.example.two,ru.example.app
```

Для этого репозитория файл доступен напрямую:

```text
https://raw.githubusercontent.com/zuboleo/split-tunnel-apps/main/public/app_ids.txt
```

Его можно использовать как удаленный список для правил split tunneling.

## Данные

- `data/apps.json` — текущий набор приложений и их состояние.
- `data/evidence.json` — найденные подтверждения и ссылки на источники.
- `data/seed.json` — исходный проверенный набор.
- `data/allowlist.txt` — приложения, которые нужно включать принудительно.
- `data/denylist.txt` — приложения, которые нужно исключать из результата.
- `public/status.json` — информация о последнем обновлении.

## Источники

Проект использует публичные публикации и страницы приложений. Для определения Android package ID предусмотрены отдельные адаптеры для Google Play, RuStore, Huawei AppGallery и Samsung Galaxy Store.

Новые источники можно добавлять независимо, не меняя формат итогового списка.

## Обновление

Актуальный список пересобирается автоматически один раз в сутки через GitHub Actions. Если новых подтвержденных приложений не найдено, файл остается без изменений.
